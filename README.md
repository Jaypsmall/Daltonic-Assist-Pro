# 👁️ Daltonic Assist (v1.0.2) ![Android](https://img.shields.io/badge/Android-181717?style=flat&logo=android&logoColor=green) ![Flutter](https://img.shields.io/badge/flutter-181717?style=flat&logo=flutter&logoColor=green)

**Daltonic Assist** es una aplicación de accesibilidad visual en tiempo real, diseñada para ayudar a personas con deficiencias en la percepción del color (daltonismo). A través de la cámara del dispositivo, la aplicación procesa el entorno para aislar, resaltar y contrastar dinámicamente las frecuencias de color que resultan más problemáticas.

## ✨ Características principales

* **🔬 Aislamiento de canales de color:** Filtra de forma selectiva los canales **Rojo (R)** y **Verde (G)** para ayudar a identificar al instante elementos que puedan generar confusión en el entorno.
* **🔄 Modos de visualización avanzados:** 
    * **Modo de patrones dinámicos (Wave):** Superpone patrones visuales (como líneas de contraste) sobre los colores problemáticos, permitiendo distinguirlos sin alterar el resto de la imagen.
* **⚡ Control de frecuencia (Hz):** Permite ajustar la tasa de refresco del procesamiento visual (desde 3.0 Hz hasta más de 8.0 Hz), adaptando la sensibilidad de la aplicación a las condiciones de iluminación y a la comodidad del usuario. * **🎯 Perfiles especializados:** Configuración rápida, con un solo toque, para los tipos más comunes de daltonismo:
    * **Protanopía** (Insensibilidad al color rojo)
    * **Deuteranopía** (Insensibilidad al color verde)
* **🔍 Zoom integrado:** Control de ampliación digital fluido para analizar detalles pequeños o texto distante, manteniendo activo el filtro de color.
